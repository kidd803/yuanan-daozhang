# 圓安道長文章搜尋

這是給信眾公開查詢圓安道長 Facebook 文章的 GitHub Pages 靜態網站。

## 目前內容

- 收錄文字文章：2,328 篇
- 日期範圍：2015-12-11 到 2026-06-29
- 分類：12 個
- 系列：9 個

## 公開版排除內容

這個版本刻意不放：

- Facebook 原始 ZIP
- 原始 JSON
- Messenger 對話
- 銷售與營運資料
- 本機伺服器紀錄
- 圖片與影片原始檔

純圖片、沒有文字的 1,074 篇貼文保留在本機原始資料中，暫不放到公開版。

## 使用方式

直接開啟 `index.html` 即可瀏覽。上傳 GitHub 後，可以在 GitHub Pages 設定中選擇從 `main` 分支根目錄發布。
