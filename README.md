- 收錄文字文章：1,953 篇
- 收錄文章圖片：4,175 張
- 日期範圍：2015-12-11 到 2026-06-29

- 原系列：9 個，完整保留
- 已合併重複影片分段：375 筆

## 公開版排除內容

這個版本刻意不放：

- Facebook 原始 ZIP
- 原始 JSON
- Messenger 對話
- 銷售與營運資料
- 本機伺服器紀錄
- 影片原始檔

純圖片、沒有文字的 1,074 篇貼文保留在本機原始資料中，暫不放到公開版。文字文章附帶的圖片已放入公開版。

## 使用方式

直接開啟 `index.html` 即可瀏覽。上傳 GitHub 後，可以在 GitHub Pages 設定中選擇從 `main` 分支根目錄發布。
