# 一柱論命演算法規格書 v1.0

## 理論定位

名稱：生肖紫微・一柱論命

創立者：林圓安道長

理論基礎：

- 紫微斗數生年四化
- 道教承負思想
- 五行生剋
- 修心理論

定位：

利用出生年一柱推演先天承負，再結合每日天地之氣，提供每日氣勢判斷與修心方向。本系統第一版會判斷今日偏順、平穩或有阻，但不作恐嚇式斷語；核心問題是：「今天氣勢如何、應修什麼心、如何調整、讀哪類文章。」

## 輸入資料

第一版輸入：

- 姓名
- 西元出生年，例如 1981
- 農曆月日，例如三月十五
- 出生時辰，例如子時、丑時；若不確定可留空
- 系統自動換算出的出生年干
- 系統依農曆月日與時辰自動推算出的命宮主星

第一版以西元出生年約換算干支年，例如 1981 年約為辛酉年。姓名、農曆月日與出生時辰作為每日修心修正資料。畫面不顯示年干與命宮主星欄位，避免一般使用者被術語干擾；主星由系統自動推算。

## STEP 1：取得出生年干

從西元出生年換算十天干：

甲、乙、丙、丁、戊、己、庚、辛、壬、癸。

西元年干支換算以 1984 年為甲子年基準：

```text
yearIndex = (西元年 - 4) mod 60
```

若輸入無法辨識，第一版使用 1981 年、辛年作為示範值。

| 四化 | 一柱論命定義 |

## STEP 3.5：推算命宮主星

命宮主星不由使用者填寫，系統依出生資料自動推算。

紫微斗數相關文案必須以站內「紫微斗數推演99講」系列為主要參考來源。若 99 講尚未整理到對應星曜或規則，第一版只輸出保守修心提醒，不新增沒有依據的斷語。

第一版採用十四主星基本安星規則：

1. 以「寅起正月，順數至生月，逆數生時」取得命宮。
2. 依出生年干取得寅宮起干，再推得命宮天干地支。
3. 依命宮天干地支取得五行局，例如木三局、金四局、水二局、火六局、土五局。
4. 依農曆出生日與五行局安紫微星。
5. 依紫微星位置安紫微星系，依天府星位置安天府星系。
6. 命宮所落十四主星，即為本次命宮主星。

公開版同步輸出「本命簡式命盤」：本命盤固定不隨每日改變，只顯示命宮、十二地支宮位、十四主星落點與可辨識的生年四化標記。完整十二宮解釋、身宮、大限、流年、輔星煞曜與深度解讀，保留為後續進階版。

每日變動的不是本命命盤，而是「今日干支五行如何觸動本命四化」。前台應避免讓使用者誤會成命盤或四化每天重新生成。

例如：

```text
1981 年辛酉生，農曆七月初四，丑時
命宮推得乙未命宮
五行局為金四局
命宮主星為天梁
```

## STEP 4：取得今日天地之氣

每日依本機日期計算干支日。

第一版採用儒略日數 JDN 公式：

```text
dayIndex = (JDN + 49) mod 60
```

其中 `0 = 甲子日`，再由日干取得今日五行。

## STEP 5：生年五行 × 今日五行

年干五行：

| 天干 | 五行 |
|---|---|
| 甲、乙 | 木 |
| 丙、丁 | 火 |
| 戊、己 | 土 |
| 庚、辛 | 金 |
| 壬、癸 | 水 |

五行作用以「今日五行」作用於「生年五行」為主。

| 作用 | 解讀 |
|---|---|
| 今日生我 | 得助力，適合整理資源、建立制度、完成工作 |
| 今日剋我 | 壓力明顯，容易急躁、衝突、口舌 |
| 我生今日 | 外放耗神，宜節制精神與時間 |
| 我剋今日 | 需要承擔與校正，宜謙卑請益 |
| 同氣相扶 | 節奏穩定，但須防固執 |

## STEP 6：承負修正

每一個四化主星都有五行屬性。第一版使用主星五行與今日五行互動，判斷是否觸動四化。

第一版主星五行表：

| 星曜 | 五行 |
|---|---|
| 廉貞、太陽 | 火 |
| 天機、貪狼 | 木 |
| 紫微、天府、天梁、左輔 | 土 |
| 武曲、七殺、文昌 | 金 |
| 破軍、太陰、天同、天相、巨門、右弼、文曲 | 水 |

承負修正規則：

- 今日同氣、今日剋該星、該星剋今日，視為觸動。
- 若觸動化忌，優先提醒執著、口舌、衝動、反覆糾結。
- 若化祿得生或同氣，提醒今日有助力，但仍須守分寸。

## STEP 7：修心模型

輸出先判斷「今天氣勢好不好」，再給出「今天應修什麼」。

第一版採加權判斷，不是固定模板：

- 出生年四化決定本命承負與人生課題。
- 命宮主星提供本命習氣與修心切入點。
- 今日五行作用決定主要受力方向。
- 農曆出生月提供月氣修正。
- 農曆出生日提供日位修正。
- 出生時辰提供時辰修正；若不確定則不計入。
- 若化忌被今日觸動，優先提高「放下」或「忍辱」權重。

前台輸出必須讓使用者看見推算差異：

- 今日氣勢：偏順、平順、平穩、有阻、偏逆。
- 今日易失衡之處。
- 推算路徑：出生年、本命四化、今日天地、生日修正。
- 命宮主星：由系統自動推算，並用白話說明其修心傾向。
- 今日主修與修法。
- 推薦文章原因。

| 情境 | 今日主題 | 宜 | 忌 | 功課 |
|---|---|---|---|---|
| 今日剋我 | 忍辱 | 靜坐、慢回話 | 爭辯、急證己見 | 清靜經、忍辱降心 |
| 觸動化忌 | 放下 | 少攀緣、少比較 | 鑽牛角尖 | 觀照起心動念 |
| 同氣相扶 | 守中 | 守規律 | 固執、拖延 | 靜坐、清靜經 |
| 今日生我 | 整理 | 建立制度 | 貪多 | 龍門心法、戒行精嚴 |
| 我生今日 | 節制 | 保留體力 | 過度付出 | 養氣、收心返照 |
| 我剋今日 | 謙卑 | 請教、校正方法 | 驕慢、指責 | 重陽立教十五論 |

## STEP 8：文章推薦

依今日修心主題建立搜尋關鍵字，再從站內文章中依標題、系列、標籤、內文加權推薦三篇文章。

## 第一版限制

- 不做完整農曆生日換算，西元年僅作干支年約換算。
- 第一版只推命宮十四主星，不排完整紫微命盤。
- 公開版只顯示本命簡式命盤，不提供完整盤解讀。
- 若命宮無十四主星，第一版暫不借對宮。
- 不判斷流年、流月、流時。
- 不輸出絕對吉凶；只輸出今日氣勢基調與修正方向。
- 今日干支採程式公式，日後可再與農民曆資料校對。
